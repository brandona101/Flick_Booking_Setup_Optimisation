Allocation rules

A rule restricts a setup to a specific list of allowed techs. Use rules for licensed services (e.g. VIC Sharps), key-account-only sites, or any service / customer with a tech-specific routing requirement.

Where this rule applies

Cover absence —

Select the day(s) being missed. The tool will categorise affected setups by urgency:
Urgent (Weekly, 2-Weekly) — must be redistributed to other techs same week.
Flexible (4-Weekly+) — can be deferred to next cycle without breaching contract.

Absentee Search — find re-routed cover

Select a tech and the day(s) they're absent. The tool finds the best nearby cover for each affected setup, prioritising by urgency — weeklies must be done today, 2-weeklies need same-week cover, 4-weekly+ can be deferred.
